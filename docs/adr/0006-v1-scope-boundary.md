# v1 范围：观感对比台，而非选型百科

v1 只交付 React 三库（Ant Design、MUI、shadcn/ui）在同一用户管理场景下的表单（Modal）与表格观感对比，外加实用档案与 URL 可分享。明确不做并排双库、评分推荐、Vue Showcase、暗色/i18n/后端、全站强隔离与实验室级指标。范围收缩是为了先验证「切换看同一业务形态」是否有用，再考虑扩展。

**Status:** v1 边界仍描述已交付的 React-only 产品。多框架扩展（Framework-first、Vue/Element Plus、Vue Island 等）见 ADR-0007 及后续 ADR，不回溯修改 v1 已交付承诺的字面范围。
