# 第一版仅覆盖 React 组件库

平台主目标是观感对比，而非跨框架百科。第一版 Showcase 与候选库只做 React，避免双运行时基建拖垮 MVP。档案信息仍可标注「另有 Vue 版」等，但不提供 Vue 真机展示。

**Status:** superseded by the multi-framework expansion decisions (Framework-first IA; Vue first batch Element Plus; React Shell + Vue Island in ADR-0007). v1 交付物本身仍是 React-only；扩展范围不再以「永久仅 React」为假设。
