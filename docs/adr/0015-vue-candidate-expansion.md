# Vue 候选扩展：Naive UI / Ant Design Vue / Arco Design Vue

在 Element Plus 与 Vue Island 基建之上，本批新增三个 Vue Candidate Library 真机 Showcase 与 Library Profile：Naive UI（`naive-ui`）、Ant Design Vue（`ant-design-vue`）、Arco Design Vue（`arco-design-vue`）。场景、共享 Showcase Data、Modal 表单与现有库全对齐；均以 React Shell + Vue Island 挂载。Vue 默认库仍为 Element Plus；Switcher 顺序 Element Plus → Naive UI → Ant Design Vue → Arco Design Vue。Ant Design Vue 与 React Ant Design 分列候选，不合并。样式隔离默认 L1；业务中文 + 官方 locale。明确不做：更多未决议 Vue 库、Vuetify 等本批未选库、并排对比、推荐引擎、外壳 Vue 化、iframe 默认隔离。目标是让 Vue 侧同样具备可切换的中后台观感对比，而不是做成 Vue 组件库百科。
